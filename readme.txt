UNDANGAN KHITANAN - Abizar Adriana Yusuf

SIAP DI-HOSTING

Website ini statis; tidak memerlukan instalasi, build, atau backend.

1. Pastikan index.html berada di root folder website.
2. Upload seluruh isi folder project, termasuk folder css, js, dan assets.
3. Untuk Netlify Drop, tarik folder project ke halaman Netlify Drop. Untuk hosting lain, upload file dan folder yang sama ke root website (biasanya public_html).
4. Buka URL hasil hosting dan uji musik, tombol Google Maps, RSVP WhatsApp, serta tautan kalender.

PENTING

- Jangan upload index.html saja. File musik harus ikut tersedia pada assets/Khitanan.mp3.
- Autoplay bersuara dapat diblokir oleh browser/perangkat. Jika musik tidak mulai otomatis, tamu dapat menekan tombol musik.
- Alamat, jadwal, dan nomor WhatsApp dapat diubah di js/data.js.
